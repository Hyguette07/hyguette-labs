# MoveFlow

Smart transportation operations: delay-aware trips, digital tickets, and a driver/admin operations desk.

**Status:** Designed; implementation is Phase 4 of the portfolio plan. AgriPulse is the first complete product.

## Problem

Passengers cannot trust arrival times. Operators cannot see which vehicles are delayed until complaints arrive.

## Solution (to implement)

- Passenger and driver identities, vehicles, routes, stops, schedules
- Booking and digital tickets
- Estimated travel time, delay flags, ETA
- Notifications for cancellation, delay, booking confirmation
- Maps for route visualization

## Stack

Java 17, Spring Boot, PostgreSQL, JWT, Next.js, TypeScript, Tailwind CSS, Docker.

Do not treat this README as a finished product until the API and UI exist in this folder the same way AgriPulse does.
