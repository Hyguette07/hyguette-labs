# Isimbi Hyguette

Software engineer building systems for problems that actually show up in the world: farms, buses, classrooms, clinics, and coordinated response.

I care about **clear domain models**, **secure APIs**, and **interfaces people can use under pressure** — not dashboards that only look busy.

## What I build

- **AgriPulse** — weather-aware decision support for smallholder agriculture
- **MoveFlow** — trip intelligence, bookings, and delay-aware transport operations
- **LearnSphere** — learning progress, assessment, and targeted revision
- **MediBridge** — privacy-first healthcare appointment coordination
- **NexusOne** — real-time emergency resource coordination (async + WebSockets)

## Stack I actually use

**Backend:** Java, Spring Boot, Spring Security, JPA, REST, FastAPI  
**Frontend:** Next.js, React, TypeScript, Tailwind CSS  
**Data:** PostgreSQL, Redis  
**Delivery:** Docker, GitHub Actions, OpenAPI, automated tests

## Engineering interests

Relational design, authorization, observability, and making distributed pieces fail in a way operators can understand.
